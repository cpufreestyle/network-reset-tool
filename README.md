# 网络重置工具

Windows 网络重置批处理脚本，**自动保留静态IP配置**。

## 功能

- ✅ 重置 Winsock 目录
- ✅ 重置 TCP/IP 协议栈
- ✅ 重置 IPv6 协议
- ✅ 清除 DNS 缓存
- ✅ 清除 ARP 缓存
- ✅ 释放并续约 DHCP
- ✅ **自动备份并恢复静态IP配置**

## 兼容性

- Windows 7 及以上（32位/64位）

## 使用方法

1. 右键点击 `network-reset.bat`
2. 选择 **"以管理员身份运行"**
3. 按提示操作

## 特点

- 自动检测使用静态IP的适配器
- 重置网络前备份配置
- 重置后自动恢复静态IP
- 无需手动记录IP地址

## 注意事项

- 必须以管理员身份运行
- 建议在执行后重启电脑
